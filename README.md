# 个人工作台 · Personal Workbench

一个只跑在自己电脑上的本地工作台：管实习准备（任务、灵感、复盘、面试记录、文件预览）和雅思学习。
**零依赖**：Node 22 内置 `node:sqlite`，不装任何 npm 包。

## 跑起来

```bash
node server.js --open
```

Windows 用户直接双击 `启动工作台.bat`。浏览器打开 `http://127.0.0.1:7788`。

> 首次运行会自动建 `data/workbench.db` 和 `config.json`（这两个文件不进仓库，见 `.gitignore`）。

## 功能

| 模块 | 作用 |
|---|---|
| 工作台 | 今日聚焦、逾期、本周完成、雅思四项均值；灵感一叠卡（鼠标放上去扇开、可洗牌抽一张） |
| 任务看板 | 待办 / 进行中 / 已完成，按模块筛选，P0-P2 优先级 + 截止日 |
| AI 规划 | 给一个模糊目标，模型拆成可执行小任务，勾选后进看板（需配 OpenAI 兼容接口） |
| 灵感库 | 全部灵感，可置顶、转任务、删除 |
| 复盘日记 | 每完成一个任务自动落一条「做到哪一步 + 学到什么」 |
| 面试记录 | 公司 / 岗位 / 轮次 / 结果 / 问题 / 复盘 |
| 学习打卡 | 雅思四项 + Agent 学习共用一张表，记分数与时长 |
| 文件预览 | 挂载本地文件夹（只读），图片 / PDF / Markdown 直接看，docx/xlsx 调本机程序打开 |
| 设置 | 配模型接口、挂载文件夹、导出全部数据 |

## 设计上的两个硬规矩

1. **完成任务 = 写复盘**：勾一下不会直接变完成，必须先写「实际做到哪一步」和「学到了什么」，两段都填才落成 `done`，同一次请求里插入一条 review。这样三个月后能分清哪些是真做完的。
2. **本地文件只读**：路径越界（`../`、绝对路径）一律 403，应用永远不会改你的文件。

## 技术栈

- Node 22 + `node:sqlite`（`DatabaseSync`），零第三方依赖
- 单页前端：`public/index.html` + `style.css` + `app.js`，无框架，黑白灰配色
- 数据表：`tasks` / `ideas` / `interviews` / `logs` / `reviews`

## 目录

```
server.js           HTTP 服务 + API + 静态资源 + LLM 代理 + 文件预览
db.js               建表、迁移、时间工具
public/             前端三件套
做工作台-skill/      把做这套工作台的方法论沉淀成可复用的 SKILL.md
使用说明.md          给自己看的使用手册
启动工作台.bat       Windows 一键启动
```
